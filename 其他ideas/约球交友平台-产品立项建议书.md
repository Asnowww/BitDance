# 约球交友平台产品立项建议书

## 一、项目概述

### 1.1 项目名称

球搭

### 1.2 项目定位

面向同城体育爱好者的约球、交友与轻赛事平台，首期以羽毛球为主打场景，围绕发布球局、报名审核、平台担保支付、赛后互评和信用沉淀建立完整交易闭环，并在此基础上延伸出球搭子关系、固定队伍、积分排名和轻赛事组织能力。

### 1.3 立项结论

建议立项。当前同城约球需求一直存在，但用户通常分散在微信群、QQ群、朋友圈、本地论坛和闲置交易平台中完成组局，流程割裂、信任成本高、放鸽子问题严重、赛后关系难沉淀。本项目的核心价值不是简单做一个活动发布工具，而是把约球、支付担保、信用体系和熟人化社交关系打通，形成可持续增长的平台型产品。

## 二、为什么应当投入资源做这个项目

### 2.1 真实需求已经存在，而且足够稳定

大众运动和同城健身活动本身就是长期需求。国家体育总局发布的《2025年全民健身活动状况调查公报》显示，经常参加体育锻炼的人数比例达 38.52%，45.1% 的 19 岁及以上居民参加过群众体育赛事活动，羽毛球和篮球处于参与度最高的项目之列。[参考1](#ref-1) 这意味着，体育爱好者不仅存在运动需求，也存在持续参与线下活动和赛事的现实场景。

同时，国家统计局发布的《2025年居民收入和消费支出情况》显示，2025 年全国居民人均教育文化娱乐消费支出为 3489 元，同比增长 9.4%。[参考2](#ref-2) 这说明文化、娱乐和运动相关消费仍在持续增长，用户愿意为体验、活动和服务付费。

从供给角度看，羽毛球、篮球、网球、足球、乒乓球等项目的同城组局需求天然高频，且大多数场景都存在以下共性问题：

1.  临时缺人，需要快速补位。
2.  不熟的人一起打球，需要先判断水平和球品。
3.  主办方要先垫付场地费和耗材费，存在收款风险。
4.  报名后临时放鸽子，容易引发矛盾。
5.  打完球后彼此认可的人很难沉淀成长期搭子关系。

因此，这个项目不是创造一个新需求，而是在已有高频场景中，用更完整的产品机制降低组局摩擦和信任成本。

### 2.2 现有方案能凑合用，但没有真正解决核心问题

用户现在一般会用三类方式约球：

1.  社交群组：微信群、QQ群、小红书同城帖、朋友圈。
2.  闲置交易或本地平台：通过类似二手交易平台的方式发布活动并收款。
3.  熟人局：靠线下球友圈、校友圈、同事圈拉人。

这些方式都能临时组局，但有明显缺陷：

1.  信息不标准，时间、地点、人数、费用、耗材、水平要求经常不完整。
2.  报名和支付分散在聊天、转账和私信里，主办管理成本高。
3.  缺少平台担保，钱款纠纷、退费争议和临时放鸽子难处理。
4.  缺少结构化评价和信用沉淀，新人是否靠谱只能凭感觉。
5.  球技、球品、守时和沟通体验无法被平台化记录，优秀用户难沉淀。
6.  同城约球关系停留在一次性组局，很难自然发展为固定搭子、固定队或长期社交关系。

也就是说，市场上不缺发布信息的地方，缺的是一套完整的组局、成交和信任机制。

## 三、现有产品的旧体验与本产品的新体验

### 3.1 旧体验是什么

| 场景 | 旧体验 | 造成的问题 |
| --- | --- | --- |
| 发起球局 | 主办方在群里发一段文字，信息格式全靠自己组织 | 报名信息不完整，后续要反复解释 |
| 确认队友 | 靠聊天判断对方水平和是否靠谱 | 误判概率高，容易影响一整场体验 |
| 收款 | 参与者私聊转账给主办方 | 主办收款麻烦，参与者也不放心 |
| 临时退出 | 靠双方私下沟通退款 | 容易产生扯皮和不公平感 |
| 打完以后 | 留在聊天记录里的只是一场局 | 优秀球友难沉淀，差评用户也难识别 |
| 继续组局 | 每次从头找人 | 缺乏长期关系积累，重复成本高 |

### 3.2 新体验是什么

| 场景 | 新体验 | 用户获得的核心价值 |
| --- | --- | --- |
| 发起球局 | 主办方按结构化表单发布球局，写清场地、时间、人数、费用、耗材和水平要求 | 信息清楚，报名门槛明确 |
| 报名入队 | 报名者展示运动水平标签、历史评价和信用记录，主办审核通过后入队 | 降低组错队友的风险 |
| 支付结算 | 报名费先支付到平台托管，活动完成后再结算给主办 | 主办和参与者都更安心 |
| 局后反馈 | 双方围绕球技、球品、守时、沟通体验进行结构化评价 | 信任关系可以持续沉淀 |
| 继续约球 | 平台自动识别常一起打球的人，推荐球搭子、固定车队和相似局 | 从一次性组局变成长期关系 |
| 平台成长 | 用户有积分、排名、战绩、MVP 记录和赛事参与记录 | 留存不只来自组局，还来自成长和社交 |

### 3.3 新体验的核心在哪里

本项目的新体验不在于发布一条约球公告，而在于把整个流程做成闭环：

1.  从发局开始就是标准化信息。
2.  从报名开始就带有信用和水平参考。
3.  从付款开始就进入平台担保规则。
4.  从完赛开始就沉淀评价、关系和成长记录。
5.  从一场临时局，延伸到球搭子、固定队伍和轻赛事体系。

## 四、产品方案与核心功能

### 4.1 目标用户

首期目标用户建议聚焦为三类：

1.  有稳定运动习惯、经常需要找人打球的同城个人用户。
2.  有组局能力、愿意定期发起球局的主办方用户。
3.  校园、企业、社区等场景中的轻赛事组织者和固定队伍。

### 4.2 核心主流程

平台首要跑通的流程如下：

1.  主办方发布约球公告。
2.  填写场地、时间、人数、费用、消耗品和水平要求。
3.  其他用户报名。
4.  主办审核通过后入队。
5.  报名者先付款到平台。
6.  活动完成后平台结算给主办。
7.  双方赛后互评球技、球品、守时和沟通体验。

这个流程构成平台最基础的价值闭环：能组局、能成交、能建立信任。

### 4.3 功能层级规划

#### 核心约球层

1.  发布约球公告。
2.  支持羽毛球、篮球、网球、乒乓球、足球等项目分类。
3.  填写时间、地点、人数、费用、是否含球、场地费、饮水等信息。
4.  设置报名门槛，如水平、性别、年龄段、是否接受新手。
5.  支持娱乐局、训练局、上分局、比赛局等活动类型。
6.  报名、审核、入队、候补、提醒、完赛确认。

#### 信任与风控层

1.  平台担保交易。
2.  主办信用分与参与者信用分。
3.  放鸽子记录与守时率。
4.  已完成场次数。
5.  差评原因分类。
6.  身份认证、学校认证、公司认证、社区认证。
7.  真人头像或实名可选认证。

#### 社交关系层

1.  个人主页。
2.  常打项目、常用位置、水平标签。
3.  常出没球馆。
4.  战绩与参与场次。
5.  好友关注、私聊、活动群聊。
6.  赛后加好友。
7.  自动识别常一起打球的人，形成球搭子关系。
8.  固定队伍、固定球局、固定车队。

#### 比赛与成长层

1.  用户水平标签。
2.  自评与他评结合。
3.  赛后更新表现标签。
4.  MVP 投票。
5.  胜负记录、积分系统、排名榜。
6.  城市榜、校园榜、球馆榜。
7.  小型积分赛、擂台赛、周赛、月赛。
8.  队伍长期战绩。

#### 主办方工具层

1.  一键发布模板。
2.  重复开团。
3.  固定队友快捷邀请。
4.  待审核名单。
5.  自动收款与结算。
6.  缺人时自动推荐候补。
7.  报名者历史评价可见。
8.  开局成本计算、收支明细。
9.  活动取消规则与替补机制。

#### 推荐与匹配层

1.  根据位置推荐附近球局。
2.  根据水平推荐合适球局。
3.  根据历史参与推荐固定队友。
4.  根据空闲时间推荐活动。
5.  自动拼局。
6.  差一人自动补位。
7.  根据评价过滤风险用户。

#### 增值服务层

1.  球馆合作。
2.  球馆优惠券。
3.  羽毛球、网球等耗材团购。
4.  教练陪练局、新手教学局。
5.  校园联赛、企业团建赛、品牌赞助赛。

### 4.4 工程复杂性体现

本项目看起来像约活动，但实际复杂度不低，主要体现在以下几个方面：

1.  不是单纯信息发布，而是信息发布、审核、支付托管、完赛确认和评价联动的交易流程。
2.  需要同时处理主办方和参与者两种角色的权益平衡，尤其是退款规则、放鸽子惩罚和自动结算机制。
3.  需要把球技、球品、守时、沟通体验等非标准化评价结构化，形成可沉淀的信用体系。
4.  平台既要满足临时补位这种即时需求，又要支持固定搭子、固定队伍和赛事组织这种长期关系需求。
5.  后续的推荐与匹配不是简单按位置排序，还要结合水平、活跃度、评价和历史协作记录。

## 五、原创性与差异化：为什么它比现有方案更值得做

### 5.1 项目的原创性判断

本项目不是从零创造同城运动社交这个品类，因此不属于品类原创。它的价值在于把目前分散在群聊、转账、私聊、熟人介绍里的流程产品化，形成完整闭环：

1.  把约球和担保支付结合起来。
2.  把球技、球品、守时和信用记录结合起来。
3.  把临时组局和长期关系沉淀结合起来。
4.  把约球平台和轻赛事成长机制结合起来。

### 5.2 与现有替代方案相比，好在哪里

| 对比对象 | 现有优势 | 现有短板 | 我们的优势 |
| --- | --- | --- | --- |
| 微信群、QQ群、本地群聊 | 熟人基础强、建群成本低 | 信息混乱、没有交易担保、评价无法沉淀 | 结构化组局、托管支付、信用体系 |
| 闲置交易或本地生活平台 | 有支付能力和本地流量 | 不是为约球场景设计，主办和参与体验不顺 | 规则专门围绕球局组织和完赛结算 |
| 熟人介绍和朋友圈拼局 | 信任高 | 圈层封闭、效率低、扩圈困难 | 让陌生人也能在可控规则下完成组局 |
| 泛社交平台和同城搭子平台 | 容易社交扩圈 | 体育活动的标准化信息、水平筛选和赛后评价较弱 | 更贴近运动场景和重复参与逻辑 |

### 5.3 为什么我们有机会做出别人没做好的点

因为多数现有方案要么擅长聊天，要么擅长支付，要么擅长内容分发，但很少专门围绕约球这一高频活动场景做深。这个场景的特点很适合平台切入：

1.  高频，尤其羽毛球、篮球、乒乓球和网球有持续组局需求。
2.  标准化程度高，时间、地点、人数、费用、水平要求都可结构化。
3.  信任问题真实存在，担保交易和信用记录有明显价值。
4.  社交关系天然可以从活动中生长出来，不需要完全靠陌生聊天冷启动。

## 六、用户价值：平台与用户的交易到底是什么

### 6.1 对参与者的价值

参与者付出的，是报名费、时间和个人运动信息。参与者换回来的价值是：

1.  更容易找到适合自己水平和节奏的球局。
2.  付款更放心，不必直接私转给陌生人。
3.  能提前看到主办和队友的历史表现，降低踩坑概率。
4.  打完以后优秀关系能够沉淀，不再每次重头找人。

### 6.2 对主办方的价值

主办方付出的，是场地组织成本和时间。主办方换回来的价值是：

1.  更容易快速补齐人数。
2.  更容易筛掉不合适或不靠谱的报名者。
3.  能通过平台托管收款和结算，降低垫资和扯皮风险。
4.  能复用模板、固定队友和历史球友，降低每次组局成本。

### 6.3 对平台的核心用户价值总结

平台与用户的交易，本质上是用标准化流程、担保规则和信用体系，换取更高效、更安全、更可持续的线下运动组局体验。

## 七、如何降低替换成本

### 7.1 对用户的替换成本最小化

1.  不要求用户放弃原来的群聊和社交方式，首期可支持活动分享回微信或群聊。
2.  用户可以只用平台完成报名、支付和评价，不必一次性迁移全部社交关系。
3.  主办方可以从单场球局开始试用，不需要一开始把所有局都搬过来。
4.  平台可支持一键复用历史球局模板，降低首次使用门槛。

### 7.2 对供给端的替换成本最小化

1.  主办方不需要改变原有组局习惯，只是把收款、审核和候补管理搬到平台。
2.  平台提供收支明细、退款规则和自动提醒，替代大量重复沟通。
3.  固定队伍和老队友可以批量导入或快捷邀请，减少冷启动阻力。

## 八、市场分析：需求是否真实，市场规模是否足够

### 8.1 市场需求为什么是真需求

从体育参与侧看，国家体育总局数据显示，经常参加体育锻炼的人数比例已达 38.52%，而群众体育赛事活动参与比例也在持续提升。[参考1](#ref-1) 这说明大众运动已不是低频尝试，而是持续生活方式。

从消费侧看，国家统计局数据显示居民教育文化娱乐消费支出继续增长。[参考2](#ref-2) 这意味着，围绕运动产生的场地、陪练、赛事和社交体验具有实际付费基础。

从数字化方式看，国家体育总局在 2025 年调查中也指出，网络、APP、短视频等数字化方式在健身指导中的使用率显著上升。[参考1](#ref-1) 这说明用户已经接受通过数字平台辅助线下运动。

### 8.2 市场空间如何理解

这个项目更适合从同城高频运动人群切入，而不是一开始面向所有社交用户。市场空间可以从三层理解：

1.  底层人群够大。运动参与人口和群众赛事参与人口都在扩大。
2.  使用场景够频繁。羽毛球、篮球、乒乓球、网球等项目都存在每周多次组局需求。
3.  服务链够长。平台不仅可以赚组局服务费，还能延伸到球馆、耗材、教练、赛事和品牌合作。

因此，这不是一个只能靠广告活着的社交产品，而是具备交易和服务延展空间的垂类平台。

### 8.3 市场空白在哪里

市场空白主要在四个地方：

1.  有聊天工具，但缺少适合约球的标准化流程。
2.  有支付工具，但缺少专门面向球局的担保和结算规则。
3.  有社交平台，但缺少围绕球技、球品和守时建立的信用体系。
4.  有运动社区，但缺少从临时组局到固定队伍再到轻赛事成长的连续路径。

## 九、盈利模式：这个项目为什么有利可图

### 9.1 核心收入来源

1.  每场球局的平台服务费。
2.  支付托管和结算服务中的抽成。
3.  球馆合作佣金和场地导流。
4.  羽毛球、网球等耗材团购和分销。
5.  教练陪练局、新手局、教学局等增值服务。
6.  校园联赛、企业团建赛、品牌赞助赛等活动合作收入。

### 9.2 为什么具备盈利可行性

1.  平台不是纯内容模式，而是自带交易场景。
2.  同一用户会重复参与，生命周期价值高于一次性活动平台。
3.  一旦形成固定主办方和固定队伍，供给会持续产生。
4.  当信用和评价体系建立后，平台切换成本会提高，用户留存也会更稳定。

### 9.3 为什么不会陷入纯社交平台竞争

如果产品只是社交平台，就很容易和泛同城交友平台竞争；如果只是约活动工具，又会缺少留存。我们的优势在于：

1.  有明确高频场景。
2.  有担保交易机制。
3.  有赛后信用沉淀。
4.  有长期成长和轻赛事体系。

这四个部分叠加后，平台价值不再是单一聊天或单一发帖。

## 十、MVP 验证方案

### 10.1 MVP 范围

首版不追求覆盖所有运动项目，建议先以羽毛球为主，验证最核心闭环：

1.  发布约球公告。
2.  报名与审核。
3.  平台托管支付。
4.  完赛确认。
5.  结构化互评。
6.  信用分与放鸽子记录。
7.  私聊和活动群聊。

### 10.2 试点对象

建议选择 20 至 50 名本地羽毛球用户进行试点，覆盖三类人：

1.  经常约球的主办方。
2.  高频参与的普通球友。
3.  刚开始找同城球局的新用户。

### 10.3 MVP 成功指标

当前阶段应优先验证流程是否能跑通、用户是否愿意持续使用，而不是直接追求大规模增长。建议采用以下指标：

1.  至少成功完成 20 场球局的完整闭环。
2.  至少 70% 的报名用户愿意使用平台托管支付，而不是私下转账。
3.  至少 60% 的完赛用户愿意留下结构化评价。
4.  至少有 30% 的试点用户在完成第一场后继续参加第二场。
5.  至少有一批主办方愿意复用模板持续发局。

### 10.4 为什么必须先做 MVP

这个产品最大的风险不在于能不能发帖，而在于用户是否愿意把最敏感的环节交给平台，包括报名筛选、托管支付和赛后互评。MVP 需要优先验证四件事：

1.  主办方是否愿意把收款和审核搬到平台。
2.  参与者是否认可担保支付和评价机制。
3.  结构化信用是否真的能提高组局成功率。
4.  打完一场以后，用户是否愿意继续在平台找下一场球局。

## 十一、风险与应对

### 11.1 风险一：冷启动困难，平台初期球局不够多

应对策略：

1.  首期聚焦一个城市和一个主打项目。
2.  优先服务主办方用户，先把供给做起来。
3.  提供重复开团、候补补位和模板复用，提升主办效率。

### 11.2 风险二：支付纠纷和退款争议影响体验

应对策略：

1.  提前写清活动开始前退款规则、临时退出扣费规则和主办取消规则。
2.  平台托管资金，并设置超时自动结算。
3.  对高频争议场景建立标准客服流程。

### 11.3 风险三：评价体系被滥用

应对策略：

1.  采用结构化评价，减少情绪化长评主导。
2.  差评需附带原因分类。
3.  对恶意评价、报复性评价建立申诉机制。

### 11.4 风险四：产品范围过大，研发失控

应对策略：

1.  首期只做羽毛球主场景。
2.  首期先跑通约球、担保支付、互评和信用闭环。
3.  排名、赛事、推荐和增值服务分阶段上线。
4.  先保证主办和参与者两端体验成立，再扩展更多社交玩法。

## 十二、最终立项建议

综合需求真实性、场景频次、市场空白、替换成本和盈利模式，本项目具备明确的立项价值。

它解决的不是简单的发帖约人问题，而是线下运动组局中最核心的四个问题：找人难、收款麻烦、信任不足、关系无法沉淀。只要能把主流程跑顺，把信用和担保机制建立起来，这个平台就不只是一个约球工具，而是可以持续沉淀关系、赛事和交易能力的运动社交平台。

因此，建议立项，并采用分阶段推进方式：先做羽毛球约球闭环，再扩展球搭子关系、积分成长和轻赛事体系，最后再延展到更多运动项目和平台合作场景。
