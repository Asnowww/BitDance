# 校园情报众包网络产品立项建议书

## 一、项目概述

### 1.1 项目名称

探路者 Pathfinder

### 1.2 项目定位

面向高校学生的信息悬赏、资料交易和校园情报沉淀平台。平台围绕期末资料、课程排雷、保研去向、实验室评价、竞赛经验等高价值校园信息，建立悬赏发布、资料供给、平台分润、信用沉淀和数据聚合的完整闭环。

### 1.3 立项结论

建议立项。当前校园产品常见的问题，是试图通过弱社交、树洞或泛互助制造活跃，但大学生群体最稳定、最刚性的需求并不是陌生人社交，而是获取高质量、低噪声、可信的校园情报。本项目不做泛社区，也不依赖用户长期用爱发电，而是通过悬赏和版税机制，激励优质资料和核心经验持续进入平台，并由后台 AI 和人工协同将这些内容沉淀为结构化数据资产。对于 5 人左右的敏捷开发团队而言，这是一个技术边界清晰、场景集中、闭环明确的工程项目。

## 二、为什么应当投入资源做这个项目

### 2.1 真实需求已经存在，而且长期稳定

高校学生长期面对明显的信息差问题，尤其集中在以下几类场景：

1.  期末备考时，不知道哪一份资料最有效。
2.  选课和换老师时，缺少可信的历史经验。
3.  保研、考研、找实验室时，很多关键经验只在小范围流传。
4.  竞赛、实习、面试准备时，优质攻略不容易被普通学生获得。

这些需求不是偶发需求，而是每学期、每学年都会反复出现的高压场景。教育部发布的《2024年全国教育事业发展统计公报》显示，2024 年全国普通本科学校 1257 所、本科层次职业学校 51 所、高职专科院校 1562 所，在校生规模庞大，高校群体本身就是一个持续存在且高度密集的用户场景。[参考1](#ref-1)

从消费能力与数字习惯看，国家统计局发布的《2025年居民收入和消费支出情况》显示，2025 年全国居民人均教育文化娱乐消费支出为 3489 元，同比增长 9.4%。[参考2](#ref-2) 这说明年轻用户对于学习、资料、经验和效率工具并非没有付费意愿，只是要看到直接价值。

因此，这个项目不是创造新需求，而是将已经存在于 QQ 群、微信群、打印店、贴吧、学长学姐硬盘中的高价值信息正式产品化。

### 2.2 现有替代方案能凑合用，但始终不成体系

目前学生获取校园情报主要依赖四类方式：

第一类是熟人传播。学生通过学长学姐、同专业朋友、课程群获取资料。这类方式信任高，但覆盖面窄，弱关系用户天然吃亏。

第二类是群聊和论坛。QQ群、微信群、贴吧、小红书、树洞都能零散传播信息，但信息极度碎片化，真假难辨，历史内容难以检索和复用。

第三类是线下打印店。打印店往往掌握历年试题、复习提纲和常见考点资料，属于校园里非常真实的隐形情报中心，但它提供的是静态资料，不提供实时热度、供需匹配和知识沉淀。

第四类是开源资料库和个人云盘。虽然有些攻略质量很高，但依赖少数人自发维护，更新不稳定，覆盖范围有限，也缺少清晰的利益机制。

这些替代方案的共同问题在于：

1.  优质内容容易被锁在小圈子里。
2.  平台无法激励头部供给者持续生产。
3.  用户知道有需求，却不知道去哪里快速找到最有效的答案。
4.  高价值内容无法转化为结构化的全校知识图谱。

也就是说，市场上并不缺资料，而是缺一套把资料和需求匹配起来、把经验资产化、把数据沉淀下来的机制。

## 三、现有产品的旧体验与本产品的新体验

### 3.1 旧体验是什么

| 场景 | 旧体验 | 造成的问题 |
| --- | --- | --- |
| 期末找资料 | 到处问群、翻聊天记录、找学长学姐要文件 | 成本高，资料真假和时效性难判断 |
| 找课程经验 | 依靠零散帖子或口口相传 | 信息碎片化，难形成可靠全景 |
| 求助某类情报 | 在群里发一句求助，等别人愿不愿意回复 | 回复不稳定，优质回答缺少激励 |
| 上传优质资料 | 好心人免费分享，或者只发给熟人 | 优质内容无法持续供给 |
| 长期沉淀 | 内容散落在论坛、云盘、聊天记录和打印店 | 数据不结构化，平台无法形成壁垒 |

### 3.2 新体验是什么

| 场景 | 新体验 | 用户获得的核心价值 |
| --- | --- | --- |
| 发起求助 | 用户发布结构化悬赏，说明课程、老师、年级、资料类型和预算 | 需求表达清楚，供给更容易响应 |
| 提供资料 | 供给者上传资料或经验，支持长期售卖与持续分润 | 高质量供给有稳定激励 |
| 平台交易 | 平台托管积分或余额，完成后自动结算与分润 | 交易规则清晰，双方都更安心 |
| 长期复用 | 优质资料进入资料集市，后续持续被购买 | 一次产出可以多次变现 |
| 数据沉淀 | 后台自动归类课程、老师、学院和情报类型 | 平台逐步形成课程图谱和趋势分析 |

### 3.3 新体验的核心在哪里

本项目的新体验不在于把资料搬到线上，而在于把原本零散、隐蔽、靠熟人流转的校园情报正式变成可交易、可评价、可分润、可沉淀的数据资产。具体来说：

1.  悬赏机制解决需求方找不到信息的问题。
2.  版税机制解决供给方缺少动力的问题。
3.  后台归档机制解决资料越积越多却无法利用的问题。
4.  特权解锁机制解决平台被白嫖和低质内容淹没的问题。

## 四、产品方案与核心功能

### 4.1 目标用户

首期目标用户建议聚焦为三类：

第一类是需求高频用户，例如备考学生、选课学生、保研学生、竞赛参与者和求职准备者。这类用户有明确问题，且愿意为了节省时间和降低试错成本付费。

第二类是供给型用户，例如成绩优秀的学霸、保研成功者、竞赛获奖者、掌握优质题库的人、熟悉实验室和导师情况的高年级学生。这类用户是平台最核心的供给来源。

第三类是治理与沉淀型用户，包括高质量创作者、认证贡献者以及后续可参与审核与协作的头部用户。他们将成为平台口碑和内容壁垒的关键。

### 4.2 核心业务闭环

平台首要跑通的闭环如下：

1.  用户发布悬赏需求。
2.  其他用户上传资料或回答情报。
3.  发布者选择采纳，平台结算积分或金额。
4.  优质资料进入资料集市，继续被后续用户购买。
5.  平台根据交易和内容数据自动构建课程、教师、学院和资料类型节点。
6.  达到一定贡献标准的用户解锁更高阶的数据视图与情报能力。

这个流程对应了平台最基础的价值闭环：能发需求、能成交、能沉淀数据。

### 4.3 功能层级规划

#### 悬赏交易层

这一层负责解决信息供需匹配问题。用户可以按课程、老师、学院、年级和资料类型发布悬赏需求，设置预算、截止时间和匿名选项。供给方可以响应悬赏，上传文档、图片、压缩包或文字答案。发布者确认采纳后，平台自动完成积分或余额结算。未被采纳的需求可自动退款或延长。对用户来说，这一层的核心价值是把零散求助变成清晰交易。

#### 资料集市层

这一层负责将一次性回答沉淀为可复用资产。高质量资料在完成首次交易后，可以进入资料集市，支持后续持续售卖。用户可按课程主页、热度榜、评分、价格和时间筛选资料。资料支持预览摘要、历史评价、购买次数、最近更新时间和适用范围说明。对供给者来说，这一层的核心价值是把一次输出变成长期版税收入。

#### 版税与分润层

这一层负责建立供给激励。平台允许资料创作者持续获得后续购买分润，建议采用创作者分成与平台回收并存的模式。平台回收部分不仅用于收益，还用于积分回笼和防止平台经济系统失衡。版税后台需要展示累计收益、单份资料收益、购买次数、转化率和历史结算记录。对头部创作者来说，这一层决定他们是否愿意长期留在平台。

#### 数据图谱层

这一层是平台形成壁垒的关键。平台不会强迫用户手动维护结构化数据库，而是由后台 AI 和人工协同把交易和资料内容归并成课程、老师、学院、实验室、保研去向等节点。随着交易数据增加，平台可以形成课程热度、资料稀缺度、挂科预警、教师风格差异和学院情报分布等视图。对普通用户来说，这一层意味着平台提供的不再只是单份资料，而是全局判断。

#### 特权与贡献层

这一层负责解决白嫖和低质内容问题。平台不建议让高阶情报完全对所有用户开放，也不建议仅靠充值直接购买所有特权。更合理的机制是把部分高级能力与用户贡献挂钩，例如用户至少有一份资料被多次购买，或达到一定采纳率和信用分后，才可查看更深层的数据视图。这样既能筛掉纯消费不贡献的低质量用户，也能强化供给侧积极性。

#### AI 后台处理层

这一层不强调前台聊天式 AI，而是强调后台脏活处理。系统可以自动识别课程名、教师名、资料类型和关键词，对重复资料进行初步检测，对问题进行归类，对预览摘要进行生成，对风险内容和敏感信息进行审核。用户前台只需要简单上传与描述，结构化和归档工作由后台完成。这样可以显著降低使用门槛，同时持续提高数据质量。

### 4.4 工程复杂性体现

本项目的技术难点并不在于页面数量，而在于系统背后的机制设计和数据处理：

1.  不是单纯的资料上传下载，而是需求发布、支付托管、采纳结算、版税复购和持续分润的复合流程。
2.  需要同时处理内容交易、积分经济和平台抽成，保证激励成立且不崩盘。
3.  需要在用户不主动填结构化字段的情况下，尽可能准确地将内容归到课程和节点下。
4.  需要应对抄袭、低质内容、虚假情报和刷单套利等现实问题。
5.  要把交易流产生的数据反哺成课程图谱和情报视图，而不是停留在零散帖子层面。

## 五、原创性与差异化：为什么它比现有方案更值得做

### 5.1 项目的原创性判断

本项目不是从零创造校园互助或资料分享这个品类，因此不属于品类原创。它的价值在于重构了校园信息流通机制：

1.  把免费互助改造成带激励的情报交易。
2.  把单次回答改造成可持续分润的资料资产。
3.  把零散内容改造成可分析的全校数据图谱。
4.  把普通用户的消费行为转化为平台知识沉淀。

### 5.2 与现有替代方案相比，好在哪里

| 对比对象 | 现有优势 | 现有短板 | 我们的优势 |
| --- | --- | --- | --- |
| QQ 群、微信群 | 零迁移成本，熟人信任高 | 信息封闭、历史难检索、无法沉淀版税 | 打破圈层壁垒，交易与数据可沉淀 |
| 打印店 | 掌握历年题库，可信度高 | 内容静态，无法实时更新，也无法做关系图谱 | 既能承接资料，也能提供动态热度和悬赏机制 |
| 贴吧、树洞、论坛 | 门槛低，信息量大 | 噪声大，真假难辨，优质内容缺乏激励 | 用交易和信用筛选高价值内容 |
| GitHub 攻略库、云盘 | 内容质量高，适合少数领域 | 覆盖面窄，维护依赖少数人 | 版税机制更适合持续扩张和多学科覆盖 |

### 5.3 为什么我们有机会做出别人没做好的点

因为当前校园内真正有价值的情报，本质上都已经存在，只是被锁在各种私域渠道里。这个产品的机会不在于凭空制造内容，而在于把这些内容用更合理的利益机制和工具机制引出来。相较于泛校园社交产品，本项目具备三个优势：

1.  场景刚性更强，尤其在期末、选课、保研和竞赛节点。
2.  用户是否付费和是否贡献，都有明确可观察行为。
3.  平台沉淀的是知识资产和决策数据，而不仅是聊天流量。

## 六、用户价值：平台与用户的交易到底是什么

### 6.1 对需求方的价值

需求方付出的，是积分、少量金钱以及自己的问题描述。需求方换回来的价值是：

1.  更快获得高质量、针对性的资料和经验。
2.  降低在群聊、论坛和熟人网络中到处求助的时间成本。
3.  能通过购买记录、评分和热度判断资料是否值得信任。
4.  逐步获得课程、老师和学院层面的全景视图，减少决策焦虑。

### 6.2 对供给方的价值

供给方付出的，是已有资料、经验和知识。供给方换回来的价值是：

1.  一次产出可以持续变现，而不是只做一次性互助。
2.  优质供给者可以建立个人声誉、创作者等级和长期收益。
3.  平台能帮助其把零散资料整理成资产，而不是继续留在私人网盘。

### 6.3 对平台的核心价值总结

平台与用户的交易，本质上是用一套清晰的悬赏、交易、分润和数据沉淀机制，换取更高效、更可信的校园信息流通方式。

## 七、如何降低替换成本

### 7.1 对用户的替换成本最小化

1.  不要求用户立刻放弃原有 QQ 群、微信群和打印店渠道，平台可以先补充最难获得的高价值情报。
2.  用户可以从单次悬赏和单次购买开始使用，而不是先建立完整个人档案。
3.  前台发布体验尽量简单，重点降低发布门槛，避免复杂标签填写。

### 7.2 对供给端的替换成本最小化

1.  高质量资料供给者不需要重新生产内容，可以先上传现有资料库。
2.  打印店、学长学姐、课程高手都可以作为早期内容供给方进入平台。
3.  资料售卖、版税分润和历史收益要尽量透明，降低他们迁移成本。

## 八、市场分析：需求是否真实，市场规模是否足够

### 8.1 市场需求为什么是真需求

高校学生群体大、信息焦虑强、周期性压力明显。教育部公开数据显示，高等教育在校规模庞大，且高校课程、导师、实验室、升学与就业路径本身就构成持续的信息差市场。[参考1](#ref-1)

另外，教育文化娱乐消费支出持续增长，也说明年轻用户对学习效率、资料获取和个人发展相关支出并非没有接受度。[参考2](#ref-2)

从用户行为角度看，学生早已习惯通过数字平台解决信息问题，因此校园情报交易不是陌生习惯，只是此前缺少更适合的产品形态。

### 8.2 市场空间如何理解

这个项目更适合从细分高校场景切入，而不是一开始覆盖所有学校和所有需求。市场空间可从三层理解：

1.  底层人群充足。高校学生基数大，且每年持续更新。
2.  高压场景稳定。期末、选课、保研、考研、竞赛、实习等节点每年反复发生。
3.  服务链足够长。平台不仅可以赚交易抽成，还可以延展到打印、资料包、训练营、实验室信息、升学规划等场景。

因此，这不是一个只能靠广告活着的低价值内容社区，而是具备交易与数据双重壁垒的垂类平台。

### 8.3 市场空白在哪里

市场空白主要在四个地方：

1.  有群聊，但缺少标准化悬赏与交易流程。
2.  有资料，但缺少持续激励供给的版税机制。
3.  有论坛，但缺少可靠的结构化归档与高质量筛选。
4.  有个人经验，但缺少把经验转化为全局数据视图的后台系统。

## 九、盈利模式：这个项目为什么有利可图

### 9.1 核心收入来源

1.  悬赏交易和资料购买中的平台抽成。
2.  高价值资料包、合集包、课程专题页的增值服务。
3.  打印店合作、线下提货或打印兑换等本地服务合作。
4.  后续延展出的训练营、考前专题、竞赛资料包等场景收入。

### 9.2 为什么具备盈利可行性

1.  平台不是纯内容模式，而是自带交易场景。
2.  用户的需求反复发生，复购可能性高。
3.  头部供给者一旦建立收益预期，会持续供给内容。
4.  数据图谱一旦形成，平台就不再只是一个买卖资料的地方，而是成为校园决策入口。

### 9.3 为什么不会陷入普通资料平台竞争

如果产品只是卖资料，很容易被视为普通网盘交易站点；如果只是论坛，又会陷入灌水和低质内容。我们的优势在于：

1.  有明确需求入口，即悬赏。
2.  有供给激励，即版税。
3.  有后台沉淀，即课程和情报图谱。
4.  有特权机制，即贡献驱动的高阶权限。

这四部分叠加后，平台价值不再是单点的资料买卖，而是完整的校园情报网络。

## 十、MVP 验证方案

### 10.1 MVP 范围

首版建议严格收缩场景，聚焦期末求生和课程资料交易，先跑通以下闭环：

1.  悬赏发布与接单。
2.  资料上传与付费解锁。
3.  基础积分钱包与结算。
4.  版税分润逻辑。
5.  课程维度的资料集市页。
6.  单课程维度的热度和挂科预警指数。

### 10.2 试点对象

建议选择单校或单院系进行试点，优先在期末前两周上线，覆盖以下用户：

1.  急需期末资料的普通学生。
2.  手握历年题、笔记和总结的高年级学生。
3.  具备资料存量的打印店或课程达人。

### 10.3 MVP 成功指标

当前阶段应优先验证交易闭环和供给激励是否成立，而不是一开始追求泛校园活跃。建议采用以下指标：

1.  至少完成一批真实悬赏的发布、响应和结算。
2.  至少有一批资料在完成首次交易后被再次购买。
3.  至少形成若干门课程的资料集市页和热度数据。
4.  至少有部分供给者明确感受到版税模式优于一次性分享。
5.  至少有一部分需求方愿意在第二次需求中继续使用平台。

### 10.4 为什么必须先做 MVP

这个产品最大的风险不在于能不能做出上传和下载，而在于以下几个关键问题是否成立：

1.  供给者是否真的愿意为版税机制上传优质内容。
2.  需求方是否愿意为高质量校园情报付费。
3.  后台归档能力是否足以把内容沉淀为课程节点和趋势数据。
4.  平台是否能在一个有限校园范围内形成基本流动性。

## 十一、风险与应对

### 11.1 风险一：冷启动阶段无人接单，流动性不足

应对策略：

1.  首期聚焦期末场景，不做过宽功能扩张。
2.  团队自己准备一批高质量资料作为基础供给。
3.  邀请打印店、学长学姐、课程高手作为首批供给者。

### 11.2 风险二：积分体系失衡，导致平台经济崩盘

应对策略：

1.  控制免费积分发放上限。
2.  建立平台回收积分的抽成与消耗机制。
3.  高价值资料定价参考供需，不做全站一口价。

### 11.3 风险三：内容质量参差不齐，用户信任受损

应对策略：

1.  建立资料评分、采纳率和购买反馈机制。
2.  对低质、过时、虚假资料设置举报和下架流程。
3.  对重点内容引入人工抽检和信誉标签。

### 11.4 风险四：产品范围过大，研发失控

应对策略：

1.  首期只做期末资料与课程情报。
2.  不对接教务系统，不做复杂爬虫。
3.  先让用户行为自然生成课程节点，再由后台进行归并。
4.  先跑通交易和供给激励，再扩展保研、竞赛、实验室等长期情报模块。

## 十二、最终立项建议

综合需求真实性、市场空白、替代方案局限、技术可行性和商业闭环，本项目具备明确的立项价值。

它解决的不是普通社交平台的活跃问题，而是高校学生在高压学习环境中面对信息差时最直接、最现实的需求。只要悬赏交易、版税分润和后台归档三件事做扎实，平台就不仅是一个资料交易工具，而会逐步成长为一所学校内部的校园情报网络。

因此，建议立项，并采用分阶段推进方式：先做期末求生场景，再扩展到课程排雷、保研去向、实验室评价和竞赛经验等更长周期模块。
